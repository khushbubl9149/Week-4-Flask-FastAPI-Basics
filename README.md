# Week 4 – Student Management REST API

## Project Description

This project is a simple Student Management REST API built using Python and FastAPI. It allows users to add, view, update, and delete student records.

## Technologies Used

- Python
- FastAPI
- Uvicorn
- Pydantic

## Features

- Get all student records
- Get student details by ID
- Add a new student
- Update existing student information
- Delete a student record
- Automatic API documentation using Swagger UI

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Start the server:

   `uvicorn main:app --reload`

5. Open the API documentation:

   `http://127.0.0.1:8000/docs`

## What I Learned

Through this project, I learned how REST APIs work, how to create endpoints using FastAPI, handle JSON requests, validate input data, and test API operations using Swagger UI.
